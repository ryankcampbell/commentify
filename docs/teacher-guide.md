# Commentify: a quick guide for teachers

Commentify is a searchable bank of report card comments, sorted into **+ Going well** and **− To improve**. You pick a few comments, adjust the wording, copy them, and paste them into the grade portal. It never stores anything about a student.

## 1. Open the app

Go to **https://ryankcampbell.github.io/commentify/**

Install it so it opens in its own window like any other app:
- **Safari (Mac):** File → Add to Dock
- **Chrome:** the Install icon at the right end of the address bar

## 2. Load the starter bank

1. Download Ryan's starter file: [starter file](LINK) (`commentify-starter-comments.json`).
2. In Commentify, click **⚙** (top right), then **Import JSON**, and choose the file.

You now have Ryan's comments to start from.

## 3. Write one student's comment

1. **Search.** Start typing, with words in any order. Put **+** or **−** first to search only one side, and **#** before a tag (such as `#focus`) to show one category. You can also click a tag button under the search box.
2. **Pick.** Use ↑ ↓ and press **Enter**, or click. Picked comments collect in the panel at the bottom, under "Strengths:" and "Areas for Growth:".
3. **Tweak.** Click any picked comment's text to change the wording for this student. **✕** removes it, and **⇄** moves it to the other side.
4. **Copy.** Press **⌘ Enter** (Ctrl Enter on Windows) or click **Copy**, then paste into the grade portal. The bold headings and bullets paste on separate lines.
5. **Next student.** Press **Esc** or click **New student** to clear the panel. **⌘Z** brings it back if you cleared it by mistake.

## 4. Make it yours

- **Add a comment:** type the full sentence in the search box and choose **Add new** at the bottom of the list. Start with **−** to file it under "To improve", and add a `#tag` to categorise it.
- **Edit or delete a comment:** click **✎** beside it (or press ⌘E on the highlighted one).
- **Keep a tweak:** after you reword a picked comment, click **save** to add the new wording to your bank.
- **Change the headings or bullet:** ⚙ → Copy format.

**Your bank is yours alone.** It is stored in your own browser. Importing gives you a copy of Ryan's comments, not a link to them: your changes never affect Ryan's bank, and his never affect yours. The comments you use most rise to the top over time.

## 5. Back it up

Because the bank lives in your browser, clearing your browser data or switching computers means starting over. Every so often, click **⚙ → Export JSON** and keep the file somewhere safe. To restore it, use **Import JSON**.

*Optional, for those comfortable with GitHub:* ⚙ → GitHub sync keeps your bank in step across devices through your own private repository.

## Hotkeys

| Key | What it does |
|---|---|
| type | search |
| `+ word` / `− word` | search only Going well / only To improve |
| `#tag` | show one category |
| ↑ ↓ | move through the list |
| Enter | pick the highlighted comment (or remove it if already picked) |
| Shift Enter | pick it and keep your search |
| Tab | switch between All, + and − |
| ⌘ Enter | copy for the grade portal |
| Esc | clear the search, then start a new student |
| ⌘Z | undo "new student" |
| ⌘E | edit the highlighted comment |
| ⌘V | paste an old comment back in to reuse and edit it |

On Windows, use Ctrl in place of ⌘. Press **?** in the app at any time to see this list.
