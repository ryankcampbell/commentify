# Commentify

A fast, keyboard-first bank of report-card comments, split into **+ going well** and **− to improve**.
Search, pick a few, tweak the wording, copy, paste into your grade portal. Nothing is stored per student.

**Use it:** https://ryankcampbell.github.io/commentify/ — then Safari → File → Add to Dock (or Chrome → Install) for its own window.

- Your comment bank lives in your browser. ⚙ → Export / Import JSON to back it up or share a starter bank.
- Optional: sync the bank across devices through a private GitHub repo (⚙ → GitHub sync, fine-grained token with Contents read & write on that repo only).
- Press `?` in the app for hotkeys.

This repo contains only the app. No comment data is stored here.
